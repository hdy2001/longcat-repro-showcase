# 白玉天宫 · 裸眼 3D 视差（单文件网页）

复现小红书案例「3D 版天宫」（老王AI工具库）：一个可交互的裸眼 3D 中式天宫场景网页。

## 运行

直接双击打开 `index.html` 即可（无任何外部依赖，离线可用）。
或 `python3 -m http.server` 后访问。

**交互**：移动鼠标（手机端为触摸拖动）→ 8 个视差层以不同速度位移，营造裸眼 3D 纵深。

调试参数：`?px=0.55&py=-0.3`（-1 ~ 1）可直接设定初始视差。

## 场景构成（单 HTML，内联 SVG + CSS + JS）

| 层 | 内容 | 视差深度 |
|---|---|---|
| L0 | 蓝天渐变 + 晨光光晕 + 高空薄云 | 0.5 |
| L1 | 雾中远景宫殿群（塔 / 大殿 / 配殿剪影） | 1.6 |
| L2 | 三层云海（后景云带 / 环绕岛腰云团 / 满幅云基） | 3 |
| L3 | 悬浮白玉主宫殿（三重檐歇山顶、鸱吻、宝顶、格栅门窗、红柱金阑额）+ 悬浮岛 + 双瀑布（SMIL 流动） | 6 |
| L4 | 镜面反射平台（宫殿/云影/人物倒影）+ 白玉栏杆 + 红/白袍极小人物 | 12 |
| L5 | 前景盘龙巨柱 ×2（龙身盘绕、鳞鳍爪、龙头、火焰宝珠）+ 右上角屋檐 | 24 |
| L6 | 仙鹤 ×3（CSS 扇翅 + 滑翔动画，远近/大小/相位各异） | 16 |
| L7 | 晨光斜照光带 + 底部浮雾 | 19 |

## 对照 success criteria

- 白玉/大理石宫殿，盘龙立柱、三重檐、屋檐起翘、斗拱、鸱吻 ✓
- 宫殿悬浮云海，底部双瀑布倾泻入云（水雾脉动）✓
- 红/白长袍人物极小（与宫殿约 1:28、与悬浮岛整体约 1:40+），立于镜面平台并带倒影 ✓
- 仙鹤 3 只，姿态各异、扇翅动画 ✓
- 鼠标/触摸视差：前景龙柱（24）> 平台（12）> 仙鹤（16）> 主宫殿（6）> 云海（3）> 远景（1.6）> 天空（0.5）✓
- 白玉色 + 蓝天 + 白云，晨光侧照，空灵东方美学 ✓

## 说明

环境无可用大模型 API key，故未调用图像生成模型，全部画面为手工矢量绘制（SVG），风格对标原帖UE5概念美术的极简东方意境。
