# 应县木塔（佛宫寺释迦塔）Blender 精准复刻

## 项目概述

本项目使用 Blender 5.2.2 Python API 参数化建模，精准复刻应县木塔（佛宫寺释迦塔）——辽清宁二年（1056年）建造的现存最古老最高木结构楼阁式建筑，通高67.31米。

## 建模方法

- **参数化脚本**：`pagoda_build.py`，基于 Blender 5.2.2 Python API
- **柱子**：12棱锥台（卷杀0.92），侧脚外撇
- **屋顶**：参数化八边形曲面——凹曲屋面（举折 s^1.7）、檐口起翘（角部三次方抬升）、瓦垄凸条
- **斗拱层**：每面4朵（栌斗+横栱+出跳+散斗），整圈合并为单一网格物体
- **平座**：悬挑板+望柱+扶手+栏板
- **暗层**：矮柱+X形斜撑（抗震结构）
- **塔刹**：刹座+覆钵+五重相轮+圆光+宝盖+宝珠+刹杆+8条铁链
- **一层**：副阶廊+内槽厚墙（2.86m）+外檐柱墙（2.6m）+南北大门+木楼梯+佛像

## 复现步骤

```bash
blender --background --python pagoda_build.py
```

渲染预览：
```bash
blender --background "应县木塔.blend" --python-expr "
import bpy
sc = bpy.context.scene
sc.render.filepath = 'output.png'
bpy.ops.render.render(write_still=True)"
```

## 备注

- 各明层/暗层高度依据总高67.31m约束分配（梁思成逐层相加测绘），暗层高度按陈明达《应县木塔》研究取2.2m
- 二层以上收分按递减曲线（每层约2.2-2.5m），符合"由下至上略有收分"的文献描述
- 斗拱按54种的文献记录做类型简化（每层一圈铺作层），未逐朵还原54种形制
- 浏览器 MCP 工具在本环境不可用（JSON 传输截断），资料通过 curl 获取
